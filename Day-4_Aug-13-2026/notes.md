# Day 4 - Tables & Lists

## Understood why Tables came into picture. 

Before, tables data is stored in Field with value.


Name: Subhashini

Roll Number: 249X5A05U8

Marks: 80

---
Name: Swapna

Roll Number: 249X5A05T5

Marks: 90

---
Name: vandana

Roll Number: 249X5A05U2

Marks: 95

---
If new record comes again 

Name: Jhansi

Roll Number: 249X5A05T6

Marks: 85

Here, the field names are repeated for each record. So tables will solve this by taking fields as column names and values as each row.

| Name | Roll Number | Marks |
| ---- | ----------- | ----- |
| Subhashini | 249X5A05U8 | 80 |
| Swapna | 249X5A05T5 | 90 |
| vandana | 249X5A05U2 | 95 | 
| Jhansi | 249X5A05T6 | 85 |
