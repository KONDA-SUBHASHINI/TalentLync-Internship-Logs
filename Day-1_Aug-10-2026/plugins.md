# Day 1 - Tools

## Z.ai
Free AI chatbot/agent (GLM models) - generates text, code, slides, full-stack apps.
It offers templates for marketing copy, brainstorming, and project planning, making it easy to start new tasks quickly.
It is also useful for creating websites from prompts by generating page structure, HTML/CSS snippets, and content ideas.
https://chat.z.ai

## Kimi
AI chatbot by Moonshot AI, strong at handling long documents/context.
It is useful for summarizing articles, extracting key points, and maintaining context across longer chats.
https://kimi.com

## Additional notes
These tools can be used to explore early AI-assisted workflows, compare response quality, and learn how different chatbots handle prompts.
Testing multiple plugins helps identify the best tool for writing, research, or coding support.
