# Day 1 - HTML

## HTML Tags Used in index.html

| Tag | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares the document as HTML5 |
| `<html>` | Root element of the page |
| `<head>` | Contains meta info (not visible on page) |
| `<meta charset="UTF-8">` | Sets character encoding |
| `<meta name="viewport">` | Makes page responsive on mobile |
| `<title>` | Sets the browser tab title |
| `<body>` | Contains all visible content |
| `<h1>` to `<h3>` | Headings (h1 = largest, h3 = smaller) |
| `<p>` | Paragraph of text |
| `<b>` | Bold text |
| `<i>` | Italic text |
| `<ul>` / `<li>` | Unordered (bullet) list |
| `<ol>` / `<li>` | Ordered (numbered) list |
| `<a href="">` | Hyperlink to another page |
| `<img src="" alt="">` | Displays an image |
| `<br>` | Line break |
| `<hr>` | Horizontal line/divider |
| `<div>` | Block-level container/section |
| `<span>` | Inline container (for small parts of text) |

## Notes

### 1. Why websites came into picture
In the 1980s, the internet already existed as a network connecting
computers, but sharing data was clunky. So, for making it easy to
share and connect information across different computers, in a way
anyone could access without special software or permissions — the
website was born.

### 2. What is HTML & Tags
HTML stands for HyperText Markup Language that describes the
structure and content of a webpage. Tags are the building blocks
of HTML — keywords wrapped in angle brackets < >.

### 3. Website vs Mobile App vs Desktop App
- **Website** = no install, works everywhere, needs internet.
- **Mobile app** = install on phone, uses phone features.
- **Desktop app** = install on computer, most powerful, works offline.

### 4. Open-source AI tools to develop websites
