# Day 2 - Tools

## Create.xyz
AI app/website builder that generates full-stack sites from a text prompt.
It can create frontend pages, backend logic, and database structure automatically.
https://create.xyz

## Replit
Online AI coding platform where Replit Agent builds and deploys editable apps from a single prompt.
It is useful for quick prototyping, live collaboration, and running full projects in the browser.
https://replit.com

## Additional notes
These tools show how AI can accelerate web development by generating real code and deployable applications.
Compare their output to see which one works better for website builders and rapid app creation.
